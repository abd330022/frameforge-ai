# FrameForge AI

A bilingual Arabic/English responsive interface prototype for an AI video creation studio.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Current status
This repository contains the front-end prototype only. The create-video interaction is intentionally a demo notice; no video is generated yet. A real video-generation provider and secure server-side API integration must be selected and configured before enabling generation.

## Deploy
Connect this repository to Vercel. Vite is auto-detected; the build command is `npm run build` and output directory is `dist`.
